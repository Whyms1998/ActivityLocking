## 这是什么

「应用锁」可以禁用/拦截**任意应用中的任意界面（Activity）**——比如短视频 App 的首页推荐流、朋友圈时间线、微博闪屏页——被锁定的界面**无法启动**，而应用的其他功能完全不受影响。

在此之上它是一套完整的自律系统：**超额才锁死**的用量监督、**越用越难**的解锁验证、把「今日次数」和「今日额度」都算在账上的特赦通行证，以及能带到下一台手机的数据同步。

> 例：锁定小红书首页后，点桌面图标直接落到**搜索页**；朋友圈每天只给 20 次，用完当天不再打开，次日 0 点自动恢复。

## 功能

### 锁定与跳转

- 🔍 **全局搜索**：按 App 名称 / 包名 / Activity 类名实时搜索，搜到即可锁定
- 🔒 **双引擎锁定**：优先组件禁用（`pm disable-user`），在 HyperOS 等受限系统上自动切换为**系统级启动拦截**（`IActivityController`），全程免 Root
- ➡️ **拦截跳转（搜索优先模式）**：点图标不再「没反应」，而是直达该 App 的搜索页。目标支持 `组件|uri` 格式——既钉死组件又带深链参数，专治同 scheme 注册在多个组件时弹出的系统选择器
- 📦 **方案库**：内置小红书 / 抖音 / 微博 / B站 / 淘宝 / 闲鱼 / 拼多多 / 知乎 / 酷安 / 即刻等常用 App 的完整方案（锁哪个界面 + 跳哪条深链），一键导入；改坏可一键恢复；支持自建、修改、删除与剪贴板 JSON 导入导出
- 🎯 **场景模式**：把方案组成命名集合（如「工作模式」），一键启用/停用（停用需过解锁验证）
- ⭐ **收藏夹 + 工作台分组**：锁定记录集中管理，支持备注、跳转目标、解锁与删除分离；分组支持多选批量与拖动排序
- 🕐 **锁定历史**：所有操作留痕，收藏夹删掉的条目也能从历史找回并一键重新锁定
- 🪟 **Activity 查询**（可选）：无障碍悬浮条实时显示当前界面的包名/类名，点击复制
- 📊 **拦截统计**：今日/累计拦截次数、分 App 明细与最近拦截事件

### 自律机制

- 📛 **解锁验证（按界面自定义）**：全局默认之外，每个界面可单独设置条件；删除受锁条目同样要过验证；磁贴「全部解锁」自动取所有界面的最强条件
- 🧮 **越用越难**：答对口算题才能解锁，题数与位数可配；连续自律天数会抬高门槛而不是降低
- 🕐 **计划与豁免**：指定时段（支持跨午夜）自动全部上锁，退出后恢复原状；计划生效期间可禁用豁免
- 🎫 **特赦通行证**：与日常验证**完全独立**的另一套准入门槛——周期配额（日/周）、准入递增（多次申请等待更久/多答题）、时长递减（用得越多给得越短）；磁贴点按直达申请验证页
- 🤖 **APP 监督（限额）**：平时正常用，**超额才锁死**到次日 0 点；对象分**整包 / 单界面**两级（微信正常用、朋友圈限次数），限额维度含时段时长、时段次数、当天时长、当天次数；界面次数按**会话制**计数——同 App 内跳页不重复扣
- 🔁 **自动锁闭**：离开应用 / 退出界面 / 息屏后延迟重新上锁，全局总闸 + 每链路可覆盖；待锁队列落盘，重启/杀进程都不会丢
- 📴 **息屏清栈**：息屏时结束锁定中的 App，封死「点图标恢复任务」的绕过路径
- ⏳ **专注会话**：一段时间的集中工作，期间锁定名单整体生效
- 🛡 **防卸载保护**：设备管理器 + 自设密码，卸载前必须过验证
- 🎛 **快捷磁贴**：上锁 / 解锁 / 特赦三个磁贴

### 数据

- ☁️ **WebDAV 云端同步**：填地址 + 账号 + 密码即可上传/下载备份，支持坚果云、Nextcloud 等；逐级建目录、失败给中文原因
- 💾 **本地导入导出**：走系统文件选择器，导出为单个 JSON，换机直接导入
- 🧾 **备份内容**：9 个数据文件 + 6 组关键设置（验证条件、特赦配额、锁定强度、自设密码、连续天数、计划状态）；**WebDAV 凭据刻意不进备份**
- ↩️ **导入可撤销**：导入前自动快照，同步页一键还原
- 🛡 **防绕过**：当日已用次数/额度**既不导出也不被导入覆盖**，「导出一次再导入」不会把今天的用量洗回零

### 其它

- 🌗 Material 3，深色模式 / 主题图标，字体粗细与触控尺寸按可读性调过
- 🔗 **URL Scheme 库**：常用 App 深链查询、复制与测试
- 🧭 底部 4 Tab：收藏 / 应用 / 统计 / 设置

## 使用前提

1. 安装 [Shizuku](https://shizuku.rikka.app/zh-hans/) 并启动（无线调试配对，或电脑 adb 启动）
2. 打开本 App → 设置 → 连接 → 申请授权
3. 到「应用」页搜索目标界面并锁定

### 小米 / HyperOS 用户

- 无需开启「USB 调试（安全设置）」，系统级拦截模式不受该限制
- HyperOS 封锁了 shell 修改组件状态的能力（`Shell cannot change component state`），App 会自动使用拦截模式，效果一致
- 手机重启后，打开一次本 App 即可恢复拦截进程
- 首次从外部拉起某个 App 会弹「应用唤醒路径」确认，**必须点一次「始终允许」**，否则跳转看起来像失效
- 用 `adb install -r -t` 覆盖安装

## 工作原理

1. **组件禁用模式**（大多数设备）：通过 Shizuku 以 shell 身份执行 `pm disable-user --user 0 包名/类名`，由系统持久化禁用该 Activity
2. **系统级拦截模式**（HyperOS 等受限系统）：通过 Shizuku 启动 shell 身份的常驻进程（`app_process`），向 `IActivityManager` 注册 `IActivityController`——Android 为自动化测试预留的全局启动控制器。此后系统每次启动 Activity 都会先询问该控制器，命中锁定清单的启动请求被直接拒绝

两种模式由 App 自动选择，也可在界面状态中查看当前使用的模式。

监督与自动锁闭的判定在 App 侧的常驻服务里跑（3 秒快循环判定 + 执行、60 秒慢循环出通知），锁定规则由 `AmsController.writeRules()` 下发给 watcher，**写盘有 300ms 防抖**并落单线程队列，避免高频规则刷新拖慢主线程。

### 注意事项

- 启动控制器**系统全局唯一**：与其他同类工具（以及 `monkey` 带 `-p` 白名单时）互斥，后注册者生效。本 App 的 Watcher 每 10 秒自动夺回注册，但与其他常驻同类工具（如 FocusGuard）同时启用仍会互相干扰，建议只保留一个
- 拦截模式下的跳转目标必须能被 shell 身份拉起：**深链最可靠**（路由页必为 exported）；未导出（`exported=false`）的界面类名会被系统拒绝，锁定弹窗会自动检测并提示
- 深链要选**直达目标页**的那条，且**冷启动也要验**：有些 App 纯组件跳转热启动有效、冷启动会漂回首页，必须用 `组件|data` 同时钉住。拦截器对被锁组件一律严格拦截——若深链的路由链中途经过被锁容器，会在那一跳被拦下。锁定前用「测试跳转」确认落点
- 跳转按启动来源智能区分：**桌面点击（用户主动）永远立即跳转**；仅当跳转后由应用内部链路绕回被锁界面时，才判定深链无效并抑制跳转 60 秒
- 拦截是**启动级**的：应用任务已在后台驻留时，点图标恢复的是原任务
- 拦截模式下若 Watcher 进程被系统回收，App 会在下次启动时自动重新注册（每 10 秒自愈重试），会话状态（当日跳转计数、已用完标记）落盘在 `/data/local/tmp`，重启不丢

## 构建

```bash
git clone https://github.com/Whyms1998/ActivityLocking.git
cd ActivityLocking
./gradlew :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

- JDK 17 与 Android SDK 36（build-tools 34.0.0），或直接用 Android Studio 打开
- `local.properties` 里写 `sdk.dir=...`（Windows 用正斜杠）
- 单测：`./gradlew :app:testDebugUnitTest`（30 项，覆盖裁决链、限额削弱判定、备份信封与 WebDAV 路径等纯函数）
- 推送 `v*` tag 会触发 GitHub Actions 跑单测 + 构建并发布 Release

## 项目结构

```
app/src/main/java/com/activitylock/app/
├─ MainActivity.kt              # 导航 + 底部 4 Tab
├─ UnlockGateActivity.kt        # 磁贴全解锁的自律验证页
├─ AmnestyApplyActivity.kt      # 磁贴特赦 → 直达申请验证
├─ core/
│  ├─ LockEngine.kt             # 锁定引擎（pm → 拦截 自动降级）
│  ├─ ShizukuManager.kt         # Shizuku 命令封装

│  ├─ SuperviseEngine.kt        # APP 监督门禁判定（整包/单界面）
│  ├─ SuperviseTask.kt          # 监督对象与额度持久化
│  ├─ QuotaService.kt           # 3 秒判定执行 + 60 秒通知
│  ├─ AutoRelock.kt             # 自动锁闭延迟裁决
│  ├─ RelockPendingStore.kt     # 待锁队列落盘（跨重启）
│  ├─ AmnestyStore.kt           # 特赦通行证配额与递增
│  ├─ BackupStore.kt            # 白名单备份 / 导入 / 快照回滚
│  ├─ WebDavSync.kt             # WebDAV 上传下载（手写 HttpURLConnection）
│  ├─ AppStore.kt               # 聚合入口 + reloadFromDisk()
│  ├─ GroupStore.kt             # 工作台分组
│  ├─ ConfigPresets.kt          # 内置一键方案库
│  ├─ LockTileService.kt        # 快捷磁贴 ×3
│  ├─ RuleStore.kt / HistoryStore.kt / VerifyGate.kt / LockStrength.kt
│  └─ ...
└─ ui/screens/                  # Compose 界面（22 个屏幕）
```
