# 应用锁 · UI/UX 重构方案 v1.0

> 依据：frontend-design（Anthropic 官方设计 skill，已安装）的方法论 —— 先令牌、后布局、再自检；
> subject matter = 一款帮人少刷信息流的 Android 自律工具。
> 范围：v0.9.2 全部 14 个界面 + 导航架构 + 视觉令牌 + 文案。

---

## 0. 现状诊断

| 问题 | 具体表现 | 根因 |
|---|---|---|
| 入口难找 | 9 个二级功能全埋在「设置」的平铺列表里；方案库/场景/统计/限额使用频率高，却和低频工具混在一起 | 信息架构按"系统设置"组织，而不是按"使用频率"组织 |
| 首页无信息价值 | 收藏夹打开只有一张规则列表，锁定状态/今日拦截/场景状态都要进别的页才能看到 | 把"列表"当成了"工作台" |
| 卡片同质化 | 所有内容都是同圆角+同阴影的圆角卡片（frontend-design skill 点名的 SaaS-card kit 默认倾向） | 没有视觉层级语言：什么重要、什么次要全靠位置猜 |
| 数字不突出 | 拦截统计是自律成果的核心，却和普通文本一样大 | 缺一个"bold element"——每屏只该有一个最抢眼的东西 |
| 空状态苍白 | "还没有收藏任何界面"只有文字 | 空状态应是行动邀请，不是占位符 |
| 验证弹窗太轻 | 解锁验证是全产品最严肃的时刻，却用一个小 AlertDialog | 严肃时刻需要全屏的仪式感 |

## 1. 设计原则（本产品的四条，所有取舍向它们对齐）

1. **关卡感**：这是一个"守门"工具。状态必须一眼可辨：锁着/放行/超额/等待。用状态色和粗字重表达，不用装饰。
2. **数字即英雄**：拦截次数、限额余量、倒计时——数字是用户最关心的内容，用 tabular 数字大字呈现，一屏一个焦点。
3. **克制即品牌**：这是一个帮人克制的工具，界面自己先克制。无渐变、无装饰动效、无多余卡片；留白分组代替卡片套卡片。
4. **动词说话**：按钮和空状态全用动词短语（"添加限额""去授权""启用工作模式"），不用名词标签。

刻意避开（frontend-design 列出的 AI 默认套路）：奶油底+衬线+赤陶色、黑底荧光绿、全员圆角卡片+同款阴影、ALL-CAPS 眉题、`A · B · C` 中点连接、→ 后缀链接。

## 2. 设计令牌（Material 3 ColorScheme 映射）

### 色彩（6 个种子色，冷灰蓝石板系——"关卡"意象，刻意远离暖色 AI 味）

| 令牌 | 值 | 用途 |
|---|---|---|
| `slate/primary` | `#2C3644` | 主色：标题、主按钮、选中态（石板蓝灰） |
| `paper/surface` | `#FAFAF7` | 页面底（近白偏纸感，暗色 `#161A20`） |
| `gate/danger` | `#C0392B` | 拦截/超额/错误（砖红，非默认 Material red） |
| `pass/success` | `#2E7D5B` | 已启用/通过/允许（苔绿） |
| `wait/tertiary` | `#B07D2B` | 等待/限额进度（琥珀） |
| `line/outline` | `#D8D6D0` | 分隔线、描边（暗色 `#3A4149`） |

文字两级：正文 `#2A2E35` / 次要 `#7A8087`（暗色对调亮度）。**禁用**纯黑 `#000` 与近黑 `#111`。

### 字体与数字

- 字族：系统栈（MIUI 兰亭黑 / OPPO Sans / 思源黑体）——Android 上引自定义字体得不偿失，层级全靠**字重+字号**。
- 字阶：Display `32sp/bold`（仅数字英雄）→ Title `17sp/600` → Body `14sp/400` → Label `12sp/500`。
- **所有数字用 `fontFeatureSettings = "tnum"`（等宽数字）**：拦截计数、倒计时、限额——关卡感的核心细节。
- 禁：ALL-CAPS 眉题、单个词变色的标题、装饰性 `·` 连接。

### 形状与间距

- 圆角两档：`12dp`（卡片/输入框）、`8dp`（chips/小件）——不再一档走天下。
- 间距 4 的倍数；组间 `20dp` + 组标题（12sp 灰），**用留白分组，不用卡片框分组**。
- 动效：只保留动作反馈（解锁成功 ✓、场景切换、开关状态）200ms 内完成；页面转场用系统默认；无入场动画。

## 3. 信息架构重构

### 3.1 导航：底部 3 tab → 4 tab

```
现状：  收藏 | 应用 | 设置(9 个平铺入口)
方案：  工作台 | 应用 | 统计 | 设置
```

- **工作台**（原收藏夹升级）：状态仪表 + 场景快捷切换 + 规则列表。90% 的日常操作在这屏完成。
- **统计**：拦截统计从设置提升为一级 tab（自律成果是留存核心）。
- **设置**：只留低频配置，并且分组（见 3.3）。
- 方案库/场景/计划/限额：工作台和设置都有入口；方案库另在锁定弹窗的深链建议里可达。

### 3.2 工作台（原收藏夹）布局

```
┌──────────────────────────────┐
│ 工作台                 [⟳]   │
│ 🔒 5 个界面锁定中 · 今日拦截 12│   ← 状态行（tnum 数字）
│                              │
│ [●工作模式] [○休息模式] [+场景]│   ← 场景 chips（横滑，一键切换）
│                              │
│ ┌─ 搜索直达 ────────────────┐ │
│ │ [小红书搜索] [抖音搜索] …  │ │   ← 桌面直达快捷方式的 App 内镜像（横滑）
│ └──────────────────────────┘ │
│                              │
│ 小红书            ── 2 界面 ──│   ← 规则分组（保留现有交互）
│   └ IndexActivityV2   [开关] │
│ 抖音              ── 2 界面 ──│
│   └ MainActivity      [开关] │
│ …                            │
│ [+ 添加要锁定的界面]          │   ← 空状态/列表尾部的行动邀请
└──────────────────────────────┘
```

### 3.3 设置：平铺 → 三组

```
设置
├─ 核心功能
│   ├─ 方案库          一键配置锁界面+跳转
│   ├─ 场景模式        方案集合一键启用/停用
│   ├─ 定时计划        指定时段自动上锁
│   └─ 时长限额        每日使用上限，超额当天拦截
├─ 数据与工具
│   ├─ 锁定历史        全部操作留痕
│   ├─ Activity 查询   找到想锁的界面
│   └─ URL Scheme 库   深链查询与测试
└─ 系统
    ├─ 连接            Shizuku 状态与授权
    └─ 解锁验证        全局默认条件与防绕过
```

### 3.4 全局行动入口（解决"找不到"的另一半）

| 动作 | 入口位置 |
|---|---|
| 启用/停用场景 | 工作台 chips（免导航） |
| 全部上锁/解锁 | 系统磁贴（已有）+ 工作台状态行点击 |
| 添加搜索直达 | 方案库「直达」按钮（已有）+ 工作台搜索直达行 |
| 新建限额/计划 | 对应页面「＋」（已有）+ 工作台状态行超额提醒点击跳转 |

## 4. 逐屏方案

### 4.1 拦截统计（新 hero 屏）

```
┌──────────────────────────────┐
│ 今日拦截                     │
│    1 2                       │   ← Display 32sp tnum，全屏唯一大数字
│    次                        │
│ 累计 47 次 · 本周最常：抖音    │
│                              │
│ 抖音     ██████████░░  8      │   ← 横条按次数排序，超额红/正常绿
│ 小红书   ████░░░░░░░░  4      │
│                              │
│ 最近拦截                      │
│ 14:22 抖音 · SplashActivity  │   ← tnum 时间，次要灰
│ 13:58 小红书 · IndexV2       │
└──────────────────────────────┘
```
改动：大数字 hero 替换两张对称卡片；进度条着状态色；最近事件保留但降为次要层。

### 4.2 方案库

- 顶部分段控件：`内置 | 我的`（替换上下两个区块滚动）。
- 行瘦身：图标 + 名称 + 一行状态点（●已启用/○未导入/↻待恢复）+ 主按钮；「直达」并入长按菜单或行尾图标，减少横向拥挤。
- 状态点用 3.1 的状态色，不再用三种 chip 底色。

### 4.3 验证对话框 → 全屏验证页

```
┌──────────────────────────────┐
│                              │
│         🔒 （图标）           │
│      自律提醒：先答对一题      │
│                              │
│        37 × 4 = ?            │   ← 题面 32sp
│      [    答案    ]          │
│                              │
│   [换一题]      [确认解锁]    │
│                              │
│  停用将解锁 3 个方案的所有界面 │   ← 后果说明（文字说清楚后果）
└──────────────────────────────┘
```
改动：AlertDialog → 全屏 Activity（复用 UnlockGateActivity 的形态）；倒计时同样全屏大数字。这是"严肃时刻"的仪式感。

### 4.4 其他屏

| 屏 | 改动 |
|---|---|
| 定时计划 | 顶部加"下一窗口 23:00 · 7 小时后"倒计时行；列表行去掉双按钮，改整行点击进编辑 |
| 时长限额 | 每行进度条着状态色（正常绿→临期琥珀→超额红）；超额行加"已拦截"角标 |
| 场景 | 行内展示成员图标（最多 5 个叠放）代替纯文字计数 |
| 应用详情 | 锁定弹窗沿用现有交互；桌面入口行的"桌面入口"角标改为图标 |
| 额度提示页 | 保持现有石碑风格（已是目标形态），加"查看限额"入口 |
| 锁定历史 | 与拦截统计统一时间格式与图标；其余不动 |

### 4.5 文案规范（全部屏幕过一遍）

- 按钮/动作：动词开头——「添加限额」「去授权」「启用工作模式」；禁止「确定/提交」。
- 空状态 = 行动邀请：标题说现状，正文给下一步（"还没有场景。点右上角＋新建，勾选要一起上锁的方案。"）。
- 错误不道歉不模糊：说清发生了什么和怎么办（"Shizuku 未连接。打开连接页申请授权后重试。"）。
- 同一动作全程同名：「启用工作模式」的完成提示是「工作模式已启用」。

- [ ] 有没有新增"和别的卡片长一样的卡片"？能用留白分组就别加框。
